# NextGen-Learner-DataScience-Oct-internship-2026

Overview
  - A beginner data cleaning project focus on cleaning and exploring an applicant dataset using Python and Pandas.

Tools:-
 - Python
 - Pandas
 - Jupyter Notebook

Project Phases:-
  - Week 1: Week 1 — Foundations: Cleaning & Exploring the Applicant Dataset 

Dataset Description:
   The dataset contains applicant-related information, including:
  - Applicant Name
  - Email
  - Phone
  - Domain Applied
  - University
  - Application Date
  - Status

Goal:-
 - The goal of this project is to improve the quality and reliability of applicant data using Python and Pandas
